Reservation Internal

서비스 내부/관리자 호출용 예약 API

슬롯 정원 Redis 값 복구

Redis 장애로 유실된 slot:capacity:{slotId}를 DB 기준으로 재계산하여 복구한다. slotDate 미지정 시 오늘 이후 OPEN 슬롯 전체가 대상.

Authorizations:
(X-User-IdX-User-Role)
path Parameters
storeId
required
string <uuid>
query Parameters
slotDate
string <date>

Responses

Gateway

http://localhost:8000/api/v1/internal/reservations/stores/{storeId}/capacity/restore
