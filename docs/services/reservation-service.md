# Reservation Service

**예약 관리**
- 예약 생성(멱등키 필수)/변경(슬롯·인원)/취소, 내 예약 조회
- 매장 측 예약 목록 조회, 점주 취소, 방문 처리, 노쇼 처리
- 슬롯 생성/조회/수정/삭제(점주), 예약 가능 슬롯 조회(사용자), 예약 통계 조회

**상태**
- `PAYMENT_PENDING → CONFIRMED → VISITED / NO_SHOW / CANCELLED`
- 슬롯: `OPEN, FULL, CLOSED, CANCELLED`

**동시성 제어 (오버부킹 방지)**
- Redisson 분산락(슬롯/멱등키 단위, 3초 타임아웃)으로 정원 초과 예약 방지
- 정원은 Redis `RAtomicLong`으로 선점 후 DB 트랜잭션 처리, 실패 시 원복
- 슬롯 변경 시 두 슬롯 락을 ID 오름차순으로 획득해 데드락 방지
- Redis-DB 정원 불일치를 주기 감지하는 스케줄러(복구는 관리자 API로만 수행)

**예약금/결제 연동 & 스케줄러**
- 예약금 필요 슬롯은 payment-service와 연동(결제 생성/환불/만료)
- 취소 시 방문일까지 남은 기간에 따라 환불액 차등(3일 이상 전액, 1~2일 50%, 당일 0%)
- 결제 미완료 5분 초과 예약 자동 취소(30초 주기), 방문 1일 전/1시간 전 리마인더 발행

**Kafka 연동**
- Outbox 패턴으로 예약 확정/취소/방문/노쇼/변경/리마인더 이벤트를 `reservation.events.v1`에 발행
